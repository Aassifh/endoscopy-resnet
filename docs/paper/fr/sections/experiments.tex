\section{Expériences}
\label{sec:experiments}

\textbf{Tâches complétées.}
\begin{itemize}
  \item \textbf{T3 (dépistage) :} trois classes coloscopiques (C0--C10), centre public unique \texttt{simula}.
  \item \textbf{T1 (fine) :} baselines supervisées HyperKvasir 23 classes (B2--B6).
\end{itemize}
Les extensions (pathologie-11, JEPA sur HK-23, sonde linéaire ViT) sont définies dans la feuille de route du dépôt mais \emph{non rapportées} ici tant que les splits groupés et multi-seed ne sont pas terminés.

\textbf{Matériel.} Apple MPS (AMD Radeon Pro 5300M).

\textbf{Pré-entraînement (CNN-JEPA).} Jusqu'à 4\,000 frames non annotées (proxy : images d'entraînement étiquetées si corpus non annoté indisponible) ; checkpoints partagés pour C2--C5.
Prévu : $\sim$99\,k images fixes HyperKvasir pour un pré-entraînement domaine.

\textbf{Affinage.} Batch 16, AdamW lr $10^{-4}$ (ImageNet / JEPA) ou $10^{-3}$ (scratch), taille 224 ; arrêt anticipé sur macro-F1 validation.

\textbf{Hypothèses (exploratoires, non confirmées).}
H1 : C4 bat C1 sous labels limités.
H2 : C4 bat C3 (SE sensible au masque).
H3 : C4 $\geq$ C5 à 25\,\% de labels.
Aucune n'est soutenue sur les splits publics par image actuels sans réévaluation groupée.
