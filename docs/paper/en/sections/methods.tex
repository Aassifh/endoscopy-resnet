\section{Methods}
\label{sec:methods}

\subsection{CNN-JEPA pretraining}
\label{sec:jepa}

Given an unlabeled frame $x \in \mathbb{R}^{3\times H \times W}$, a binary block mask $m \in \{0,1\}^{1\times H \times W}$ defines visible context $x \odot m$.
A \emph{context encoder} $f_\theta$ (\backbone{}) produces a feature map $h = f_\theta(x \odot m, m)$.
A lightweight convolutional \emph{predictor} $g_\phi$ maps $h$ to a latent grid $\hat{z} = g_\phi(h)$.
A \emph{target encoder} $f_{\bar{\theta}}$ (EMA copy of $f_\theta$, momentum $\tau=0.996$) encodes the full image: $z = f_{\bar{\theta}}(x)$.
The training loss is normalized mean squared error:
\begin{equation}
\mathcal{L}_{\mathrm{JEPA}} = \left\| \mathrm{norm}(\hat{z}) - \mathrm{norm}(z) \right\|_2^2 .
\end{equation}
Block masks expose 25--45\% of pixels (multi-scale rectangles).
Pretraining uses AdamW, cosine schedule, early stopping on validation latent loss (patience 10, max 80 epochs).

\subsection{Mask-aware squeeze-and-excitation}
\label{sec:maskse}

Standard SE blocks apply GAP over all spatial locations.
When inputs are masked, zero-padded regions skew channel statistics.
Our \textbf{mask-aware SE} computes per-channel pooling over visible positions only:
\begin{equation}
\mathrm{GAP}_c(x,m) = \frac{\sum_{i,j} x_{c,i,j}\, m_{i,j}}{\sum_{i,j} m_{i,j} + \epsilon}.
\end{equation}
Channel attention weights are then applied as in SE-Net~\cite{hu2018senet}.
Ablation C3 uses standard SE under the same JEPA pipeline; C4 enables mask-aware SE.

\subsection{Data and class taxonomy}
\label{sec:data}

\textbf{T3 (screening).}
We merge Kvasir v1 and HyperKvasir labeled images into three classes:
\begin{itemize}
  \item \textbf{Landmark:} cecum, pylorus, z-line, ileum, retroflexions.
  \item \textbf{Normal mucosa:} BBPS scores, hemorrhoids, impacted stool (non-lesion frames).
  \item \textbf{Polyp:} Kvasir \texttt{polyp}, HyperKvasir \texttt{polyps} and \texttt{dyed-lifted-polyps}.
\end{itemize}
Total: \numsamples{} images, center \texttt{simula}.
Splits use \textbf{group-aware} stratification (procedure/video group per image; \texttt{prepare-colonoscopy-3class} reads HyperKvasir \texttt{image-labels.csv}).
Current public stills are one frame per group; multi-frame video groups apply when unlabeled frame pools are used.

\textbf{T1 (HyperKvasir-23).}
Official Simula 23-class folders via \texttt{prepare-hyperkvasir}; 10{,}662 images, stratified 70/15/15.

Planned extensions (not in main tables): T2 pathology-11 subset; JEPA fine-tunes on HK-23.

\subsection{Experimental protocol}
\label{sec:protocol}

\textbf{T3 (C0--C10).} Screening three-class runs with label fractions C7--C9.

\textbf{T1 (B2--B6).} ResNet, SE-ResNet, dual-stream on HyperKvasir-23 (supervised only in this manuscript).

\subsection{Metrics}
Primary: \textbf{macro-F1} on validation/test.
Clinical secondary: \textbf{polyp recall} $= \mathrm{TP}/(\mathrm{TP}+\mathrm{FN})$ for the polyp class (sensitivity among true polyps).

\subsection{Implementation}
PyTorch on Apple MPS; open repository \texttt{endoscopy-resnet}.
Campaign orchestration: \texttt{run\_full\_jepa\_benchmarks.sh}; early-stop logs per run.
