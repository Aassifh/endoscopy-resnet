# Glossary

| Term | Definition |
|------|------------|
| **CSO** | Claude Search Optimization — crafting skill descriptions so agents discover and load the right skill |
| **Skill** | Markdown instruction file (SKILL.md) with YAML frontmatter (`name`, `description`) |
| **Iron Law** | No skill without a failing test first (from writing-skills) |
| **Pressure scenario** | Test prompt designed to tempt agent into violating a discipline skill |
| **Treatment** | Superpowers enabled (plugin + skills + hook) |
| **Baseline** | Superpowers disabled |
| **Trigger rate** | Proportion of runs where expected skill was invoked |
| **Rationalization** | Agent excuse for skipping skill rules (documented in red-flag tables) |
| **Session hook** | Script run at agent session start to inject bootstrap context |
| **Worktree** | Isolated git branch/directory for feature development |
